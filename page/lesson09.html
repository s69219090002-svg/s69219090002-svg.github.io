บทที่ 9

JavaScript สมองกลผู้เนรมิตชีวิตให้เว็บไซต์

กลับหน้าหลัก
1. เปรียบเทียบองค์ประกอบการสร้างหุ่นยนต์ (HTML, CSS, JavaScript)

เปลี่ยนหน้าเว็บที่ตายตัวให้กลายเป็นแอปพลิเคชันที่มีชีวิตชีวาและโต้ตอบได้แบบเรียลไทม์[cite: 1] โดยแบ่งบทบาทหน้าที่ตามโครงสร้างหุ่นยนต์ดังนี้:

  • โครงเหล็ก (HTML): โครงสร้างและชิ้นส่วนพื้นฐานที่ประกอบกันเป็นรูปร่าง (Structure)[cite: 1]
  • เสื้อผ้าและสีสัน (CSS): การตกแต่งผิวภายนอกให้ดูสวยงามและเป็นระเบียบ (Presentation)[cite: 1]
  • สมองกล (JavaScript): ระบบไฟฟ้าที่สั่งการให้ขยับ โต้ตอบ และมีความคิด (Behavior)[cite: 1]
2. การติดตั้งสคริปต์เพื่อปลุกชีพสมองกล

การเขียนโค้ด JavaScript เข้ากับหน้าเว็บ HTML สามารถทำได้ 2 รูปแบบหลัก[cite: 1]:

รูปแบบ วิธีเขียน การเปรียบเทียบ การนำไปใช้งาน
Internal Script (การเขียนแบบภายใน)[cite: 1] พิมพ์โค้ดลงในแท็ก <script> วางไว้ก่อนปิด </body>[cite: 1] โน้ตคำสั่งสั้นๆ แปะไว้บนตู้เย็น[cite: 1] เหมาะกับโค้ดขนาดเล็ก ที่ทำงานเฉพาะเจาะจงแค่หน้าเว็บเดียว[cite: 1]
External Script (การเชื่อมไฟล์ภายนอก)[cite: 1] สร้างไฟล์ .js แยก แล้วเชื่อมด้วย <script src='main.js'></script>[cite: 1] คู่มือการทำงานแยกเป็นเล่มต่างหาก[cite: 1] มาตรฐานมืออาชีพ โค้ดสะอาด นำไปใช้ร่วมกับหน้าเว็บอื่นๆ ได้ทันที[cite: 1]
3. ช่องทางการสื่อสารของ JavaScript

เครื่องมือที่ใช้ส่งข้อความแสดงผลเพื่อโต้ตอบกับผู้ใช้หรือทดสอบระบบ[cite: 1]:

  • alert() (กล่องป๊อปอัปแจ้งเตือน): เด้งขึ้นมากลางหน้าจอ บังคับให้ผู้ใช้กด OK ส่งผลให้หยุดการทำงานของเว็บทั้งหมดชั่วคราว เหมาะสำหรับผู้ใช้งานทั่วไป (User)[cite: 1]
  • console.log() (ข้อความลับหลังบ้าน): พิมพ์ข้อความลงในเครื่องมือ Console (F12) ทำงานเงียบๆ ไม่รบกวนการอ่านเว็บ เหมาะสำหรับนักพัฒนาโปรแกรม (Developer) เพื่อทดสอบโค้ด[cite: 1]
4. DOM (Document Object Model): แผงควบคุมวงจรไฟฟ้าของเว็บไซต์

กลไกสำคัญที่ทำให้ JavaScript สั่งงานและเปลี่ยนแปลงองค์ประกอบของหน้าเว็บได้[cite: 1]:

  • 1. การแปลงร่างของ HTML: ทันทีที่เบราว์เซอร์อ่านโค้ดเสร็จ จะสร้าง DOM ขึ้นมาครอบทับเว็บไซต์[cite: 1]
  • 2. สวิตช์และปุ่มกด: แท็ก HTML ทุกตัวจะถูกจำลองเป็นสวิตช์บนแผงควบคุม (เช่น <h1>, <p>, <button>)[cite: 1]
  • 3. หน้าที่ของ JavaScript: เอื้อมมือเข้าไปสับสวิตช์ สั่งให้หน้าเว็บขยับหรือเปลี่ยนสีได้แบบเรียลไทม์โดยไม่ต้องกดรีเฟรช[cite: 1]
5. ขั้นตอนการควบคุมและแก้ไขหน้าเว็บ (DOM Manipulation)
  • ขั้นตอนที่ 1 - ล็อกเป้าหมายด้วย getElementById: ใช้คำสั่ง document.getElementById('id-name') เปรียบเสมือน "การประกาศเรียกชื่อพนักงานผ่านเสียงตามสาย" เพื่อดึงแท็ก HTML ออกมารอรับคำสั่ง[cite: 1]
  • ขั้นตอนที่ 2 - เปลี่ยนแปลงความจริงด้วย .innerHTML: ใช้คำสั่ง .innerHTML = 'ข้อความใหม่'; เปรียบเสมือน "การเดินไปที่กระดานไวท์บอร์ด ลบข้อความเดิมทิ้งจนหมด แล้วเขียนข้อความใหม่ทับลงไป" ทำให้ข้อมูลเปลี่ยนทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่[cite: 1]
  • ขั้นตอนที่ 3 - ตัวกระตุ้นการทำงาน (The onclick Event): ระบุ onclick="..." บนปุ่ม เพื่อรับสัญญาณกริ่งแจ้งเตือนเมื่อผู้ใช้กดคลิก และสั่งให้ฟังก์ชัน (Function) ทำงานทันที[cite: 1]
6. การรับรู้และดักจับพฤติกรรมผู้ใช้ (User Events)

JavaScript สามารถดักจับเหตุการณ์ต่าง ๆ ที่เกิดจากเมาส์และคีย์บอร์ดได้[cite: 1]:

ประเภท Event ชื่อคำสั่ง พฤติกรรมและการทำงาน
Mouse Events[cite: 1] onmouseover[cite: 1] ทำงานทันทีเมื่อนำเมาส์ 'ลากไปวางพาด' (ยังไม่คลิก) ใช้เพื่อดึงดูดความสนใจ[cite: 1]
onmouseout[cite: 1] ทำงานทันทีเมื่อลากเมาส์ 'ออกจากวัตถุ' ใช้คืนค่ารูปลักษณ์เดิม[cite: 1]
Keyboard Events[cite: 1] onkeydown[cite: 1] ทำงานในเสี้ยววินาทีที่ 'กดปุ่มลงไป'[cite: 1]
onkeyup[cite: 1] ทำงานทันทีเมื่อ 'ปล่อยนิ้วขึ้น' เหมาะสำหรับการตรวจสอบข้อมูลแบบสดๆ (Real-time) ขณะพิมพ์[cite: 1]
7. วงจรแห่งการโต้ตอบ (The Interactive Loop)

สรุปการทำงานร่วมกันเป็นขั้นตอนในการประมวลผลของ JavaScript[cite: 1]:

  • 1. ตัวกระตุ้น (The Trigger): ผู้ใช้งานกระทำพฤติกรรมบางอย่าง เช่น การคลิก หรือพิมพ์ (onclick, onkeyup)[cite: 1]
  • 2. ล็อกเป้าหมาย (The Radar): JS สแกนหา DOM ด้วยคำสั่ง เช่น getElementById เพื่อระบุชิ้นส่วนที่ต้องจัดการ[cite: 1]
  • 3. สมองกลประมวลผล (The Logic): เรียกใช้ Function นำค่า (.value) มาตรวจสอบเงื่อนไข[cite: 1]
  • 4. อัปเดตหน้าจอ (The Update): เปลี่ยนแปลงเนื้อหาหรือสีสันบนหน้าจอทันทีแบบ Real-time ด้วยคำสั่ง เช่น .innerHTML[cite: 1]
