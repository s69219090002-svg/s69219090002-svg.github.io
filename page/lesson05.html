บทที่ 5

การจัดการข้อความและสื่อมัลติมีเดีย

กลับหน้าหลัก
1. การจัดการข้อความระดับสูง
  • การกำหนดสี (color) และขนาด (font-size): ใช้คำสั่ง color กำหนดสีตัวอักษรได้ทั้งชื่อสีภาษาอังกฤษ, Hex Code (เช่น #FF5733) หรือ RGB และใช้ font-size กำหนดขนาด โดยควรคำนึงถึงลำดับความสำคัญทางสายตา (Visual Hierarchy) (p. 3)
  • การเชื่อมต่อ Google Fonts: บริการฟอนต์บนคลาวด์ฟรี ช่วยให้เว็บไซต์แสดงฟอนต์สวยงามได้ทุกเครื่อง โดยใช้แท็ก <link> ในส่วน <head> เพื่อดึงฟอนต์มา แล้วเรียกใช้ด้วย font-family ใน CSS (p. 3-4)
2. การแทรกรูปภาพและสื่อ
  • แท็ก <img>: แท็กเดี่ยว (Empty Tag) ไม่มีแท็กปิด ใช้แสดงรูปภาพ ต้องทำงานร่วมกับแอตทริบิวต์ src เพื่อระบุที่อยู่ไฟล์ภาพเสมอ (p. 6)
  • Relative Path vs Absolute Path: Relative คือระบุที่อยู่ไฟล์ในโฟลเดอร์โปรเจกต์ตัวเอง (เช่น src="images/coffee.jpg") เหมาะกับรูปที่เก็บไว้เอง ส่วน Absolute คือ URL เต็มรูปแบบขึ้นต้นด้วย https:// ชี้ไปยังรูปบนเว็บอื่น (p. 7)
  • การจัดการขนาดไฟล์ (Image Optimization): ควรย่อขนาดภาพก่อนใช้งานเสมอ (ความกว้างไม่ควรเกิน 1200px) และเลือกสกุลไฟล์ให้เหมาะกับงาน เช่น .jpg สำหรับภาพถ่าย, .png สำหรับภาพที่ต้องการพื้นหลังโปร่งใส, .webp สำหรับไฟล์ยุคใหม่ที่บีบอัดเล็กแต่คมชัด (p. 8)
3. การจัดการวิดีโอและเสียง
  • แท็ก <video> และ <audio>: HTML5 มีแท็กเฉพาะสำหรับสื่อมัลติมีเดีย ใช้งานคล้ายกัน ต้องระบุ src เพื่อชี้ไปยังไฟล์สื่อ (p. 9)
  • แอตทริบิวต์ controls: หัวใจสำคัญที่สั่งให้เบราว์เซอร์แสดงแผงควบคุม (เล่น/หยุด, แถบเวลา, ปรับเสียง, ขยายเต็มจอ) หากไม่ใส่ วิดีโอจะเป็นเพียงภาพนิ่งกดเล่นไม่ได้ (p. 9-10)
4. การสร้างเฟรมด้วย Inline Frame (Iframe)
  • แท็ก <iframe>: ใช้ดึงเนื้อหาจากเว็บไซต์อื่นมาแสดงในหน้าเราแบบ "เจาะหน้าต่าง" โดยไม่ต้องพาผู้ใช้ออกจากเว็บ ต้องระบุ src เป็น Absolute Path เสมอ (p. 11)
  • แอตทริบิวต์สำคัญ: width/height กำหนดขนาดกรอบ, title อธิบายเนื้อหาเพื่อการเข้าถึง (Accessibility), allowfullscreen อนุญาตให้ขยายเต็มจอ (p. 11)
  • การประยุกต์ใช้จริง: นิยมใช้ฝังวิดีโอ YouTube (Share → Embed) และแผนที่ Google Maps (Share → Embed a map) เพื่อไม่ต้องเปลืองพื้นที่เซิร์ฟเวอร์ของตัวเอง (p. 12)
