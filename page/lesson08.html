บทที่ 8

การออกแบบและสร้างฟอร์ม (Forms)

กลับหน้าหลัก
1. องค์ประกอบของฟอร์ม

ฟอร์ม (Forms) เป็นเครื่องมือสำหรับรับข้อมูลจากผู้ใช้งาน แล้วรวบรวมข้อมูลเพื่อส่งต่อให้ระบบหลังบ้าน (Server) ประมวลผล จึงเป็นส่วนสำคัญในการสร้างปฏิสัมพันธ์ระหว่างผู้ใช้งานกับเว็บไซต์

  • <form>: กำหนดพื้นที่สำหรับชุดข้อมูลที่ต้องการส่ง
  • action: ระบุ URL หรือเส้นทางของระบบฝั่งเซิร์ฟเวอร์ที่รับข้อมูล
  • method: กำหนดวิธีการส่งข้อมูล โดยบทเรียนนี้เน้น GET และ POST
2. โครงสร้าง <form> และ Action, Method

แท็ก <form>...</form> เปรียบเสมือนซองจดหมายที่บรรจุช่องรับข้อมูลและปุ่มส่งข้อมูลเอาไว้ภายใน

Methodลักษณะเหมาะกับ
GETข้อมูลถูกนำไปต่อท้าย URL และสามารถมองเห็นได้ข้อมูลทั่วไป เช่น คำค้นหา
POSTข้อมูลถูกส่งไว้เบื้องหลัง ไม่แสดงต่อท้าย URLข้อมูลส่วนตัวหรือข้อมูลที่มีปริมาณมาก
<form action="process.php" method="post">
  ...
</form>
3. การใช้ <label> คู่กับ <input>

ควรเชื่อมโยง label กับ input โดยใช้ค่า for ของ label ให้ตรงกับ id ของ input เพื่อเพิ่มความสะดวกในการใช้งานและช่วยด้านการเข้าถึง

<label for="fullname">ชื่อ-นามสกุล</label>
<input type="text" id="fullname" name="fullname">
4. ประเภทของ Input

การเปลี่ยนค่า type ของ <input> ทำให้ช่องรับข้อมูลมีหน้าตาและพฤติกรรมแตกต่างกัน

ประเภทการใช้งาน
textข้อความบรรทัดเดียว เช่น ชื่อ-นามสกุล หรือชื่อเล่น
passwordรับรหัสผ่านและพรางตัวอักษรที่พิมพ์
emailรับอีเมลและช่วยตรวจรูปแบบอีเมลเบื้องต้น
radioเลือกได้เพียงหนึ่งตัวเลือกในกลุ่มเดียวกัน
checkboxเลือกได้หลายข้อหรือไม่เลือกเลยก็ได้
select / optionเมนูแบบ Dropdown เหมาะกับตัวเลือกจำนวนมาก
5. ตัวอย่างฟอร์มที่มี Input หลากหลายประเภท
หลักการเลือก Input: เลือกเครื่องมือให้ตรงกับลักษณะข้อมูลและคำนึงถึง User Experience (UX) และความถูกต้องของข้อมูล หากต้องเลือกคำตอบเดียวให้ใช้ Radio, ถ้าเลือกได้หลายข้อให้ใช้ Checkbox และถ้ามีตัวเลือกจำนวนมากให้พิจารณา Select
6. การตรวจสอบข้อมูล (Validation)

Validation ทำหน้าที่ตรวจสอบข้อมูลเมื่อผู้ใช้กดส่งฟอร์ม หากข้อมูลไม่ครบหรือไม่ตรงตามเงื่อนไข เบราว์เซอร์จะไม่อนุญาตให้ส่งฟอร์มจนกว่าจะแก้ไขข้อมูลให้ถูกต้อง

HTML5 มีระบบ Built-in Form Validation ที่ช่วยควบคุมเงื่อนไขได้โดยใช้ Attribute ใน <input>

Attributeหน้าที่ตัวอย่าง
requiredบังคับให้กรอกข้อมูลrequired
minกำหนดค่าต่ำสุดmin="18"
maxกำหนดค่าสูงสุดmax="60"
7. ตัวอย่าง Validation
<form>
  <label for="age">อายุ</label>
  <input type="number" id="age" min="18" max="60" required>

  <button type="submit">ส่งข้อมูล</button>
</form>
8. สรุปท้ายบท
  • ใช้ <form> เป็นพื้นที่สำหรับรวบรวมข้อมูลจากผู้ใช้งาน
  • action ระบุปลายทาง และ method ระบุวิธีการส่งข้อมูล
  • GET แสดงข้อมูลต่อท้าย URL ส่วน POST ส่งข้อมูลไว้เบื้องหลัง
  • ใช้ <label> คู่กับ <input> เพื่อให้ฟอร์มใช้งานสะดวก
  • เลือก Input ให้เหมาะกับข้อมูล เช่น text, password, email, radio, checkbox และ select
  • ใช้ required, min และ max เพื่อช่วยตรวจสอบข้อมูลก่อนส่งฟอร์ม
